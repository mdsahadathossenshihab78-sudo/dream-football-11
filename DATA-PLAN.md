## Long-term data behavior
- **Refresh policy**: none; no external data. Profile/coins/squad/tournament state load from the artifact DB on open.
- **Growth**: one profile row per account (keyed by email), owned-player rows per purchase, tournament state as one JSON row per profile.
- **Ordering**: store sorted by rating desc; squad shown in formation order.
- **Time semantics**: match rewards computed server-side from the reported result with caps; no wall-clock-sensitive data.
